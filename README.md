# Studio sul formato MP3: Acustica e Tecnologia
### A cura di Fabrizio Gorni

Questo progetto nasce come approfondimento didattico e tecnico sulle dinamiche della compressione audio digitale, con un focus particolare sul formato MP3.

## 🎯 Obiettivi dello studio
L'elaborato analizza il compromesso tra qualità sonora e peso dei dati, esplorando:
* **Fisica del suono:** Le basi dell'acustica applicate al dominio digitale.
* **Psicoacustica:** I processi percettivi dell'orecchio umano.
* **Interattività:** Un percorso multimediale con esempi audio pronti all'ascolto.
